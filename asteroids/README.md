##Asteroids - Arcade Game (Boot.dev Project)

Acest proiect este o implementare a clasicului joc Asteroids, realizată în Python folosind librăria Pygame. Accentul a fost pus pe aplicarea principiilor OOP (Programare Orientată pe Obiecte) pentru a gestiona entitățile din joc (jucător, asteroizi, proiectile) și pe implementarea buclei principale de joc (Game Loop).

1. OOP: Utilizarea claselor pentru a defini comportamentul fiecărui obiect (moștenire și încapsulare).

2. Game Loop: Gestionarea constantă a evenimentelor, actualizarea stării jocului și randarea grafică.

3. Detectarea coliziunilor: Calcularea intersecțiilor dintre entitățile de pe ecran.

4. Vectori și Fizică: Gestionarea mișcării obiectelor în spațiu 2D.

Tehnologii folosite: Python 3 , Pygame (pentru grafică și input)
