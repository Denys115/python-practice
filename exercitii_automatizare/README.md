# Exerciții de Automatizare și Python

Acest folder conține diverse scripturi și proiecte realizate în etapa mea de învățare Python. Scopul lor a fost explorarea automatizării, lucrul cu baze de date (SQLite) și dezvoltarea de mici aplicații web.

## Conținut:
1. **Automatizări:** Scripturi pentru calcularea termenelor limită (`time_till_deadline.py`) și deploy (`deploy.py`).
2. **Web:** Structura de bază pentru un site (`my_website/`, `manage.py`, `db.sqlite3`).
3. **Testare:** Exerciții de logică și teste de funcționalitate (`test_proiecte.py`, `user.py`).

## Scop:
Aceste scripturi demonstrează aplicarea conceptelor fundamentale de Python în scenarii practice și de automatizare.
